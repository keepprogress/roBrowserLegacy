# REVIEW.md — keepprogress fork (caddo)

These rules add to the upstream [REVIEW.md](../REVIEW.md); everything there still applies.

**Write review comments in Traditional Chinese (zh-TW).** Code, identifiers and quoted log lines stay as they are.

## What this fork is

- `caddo` is the deploy branch of the caddokawaRo server. A merge into `caddo` is built into the Docker image that players load.
- Server: rAthena, `langtype` 4 (Taiwan, big5), `PACKETVER` 20240417, with `loadLua: true` and Taiwan client data. The game files are served by the remote client; their names are Korean (EUC-KR).
- The branch history is: upstream master → `feat(caddo): apply robrowser-caddo.patch …` → `feat(caddo): apply ui_zh.py …` → fixes → `ci(caddo): …`. Upstream is followed by rebasing, never by merging.
- Upstream workflow files are left unchanged. Their read-only checks (Lint, Format, Build, Benchmark, CodeQL) run here as upstream has them; the ones that publish or write to the repository (Pages, Pages cleanup, the Devin labelers) are disabled in the repository settings. This fork's own checks are in `.github/workflows/caddo-*.yml`.

## 🔴 Critical — Block the PR

| Area                      | What to check                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Public repository**     | This fork is public. Block anything that belongs to the deployment: private-network IP addresses, the server's domain names, game server ports or WebSocket proxy targets, `Config.local.js` content, admin or account ids (`adminList`), tokens, and generated client data (overlay text tables, textures, `.lub` produced by the server repo). These live in the private server repository, not here. Do not quote such a value in a review comment either; name the file and line.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| **Korean resource names** | GRF lookup always uses the filesystem charset (`grfCharpage`, windows-1252): sprite, texture and other file names are EUC-KR bytes and must reach the remote client unchanged. Decoding a name with the langtype charset (`userCharpage`, big5 here) makes it a different string and the file is never found (`음유시인모자` → `擠嶸衛檣賅濠`). `userCharpage` is only for user-facing text (item names, descriptions). Follow the existing loaders: `loadTable` defaults to the filesystem charset (`useCharPage = false`) and takes `true` for text tables; `loadLuaTable` defaults to the langtype charset (`useCharPage = true`) and takes `false` for the sprite name tables (`AccNameTable`, `RobeNameTable`, `JobNameTable`), as its 6th argument after `contextFunc` (pass `null` when there is none); `loadItemInfo` decodes `*DisplayName` with `userCharpage` and `*ResourceName` with the default. Decide by what the value is used for, never with a list of table names. See `docs/Encoding.md`. |
| **Robe fallback**         | In `EntityView.js`, a garment whose per-sex `.spr` is missing takes the `.spr` from the sex-less path but keeps the `.act` of the per-sex path. That is intended (upstream review on MrAntares/roBrowserLegacy#1575): do not report it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **Interface paths**       | `data-background`, `data-hover`, `data-down`, `data-active` and `data-preload` are resolved against `DB.INTERFACE_PATH` by `GUIComponent`: their value is relative to it. A value that already holds it names the folder twice and the image is never found. Direct `Client.loadFile(DB.INTERFACE_PATH + …)` calls do need the prefix.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| **ui_zh commit**          | The Chinese UI is one commit whose message starts with `feat(caddo): apply ui_zh`. `caddo CI` finds it by that message and reverts it to run the upstream tests, which check English text. Block a PR that splits it, renames it, or adds a separate commit that reformats the lines it changed (the revert then conflicts). Formatting of translated files belongs in that same commit.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |

## 🟡 Important — Request changes

| Area                     | What to check                                                                                                                                                                                                                                                                      |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Upstream first**       | A fix for a bug that upstream also has must be its own commit, with a test, and must apply to upstream master on its own, so it can be sent to MrAntares/roBrowserLegacy unchanged. Caddo-only behavior uses a `(caddo)` scope in the commit message.                              |
| **Chinese text in code** | Translated strings must not break the code around them: quotes and backticks in string and template literals, HTML entities and escaping where the string goes into `innerHTML`, `%s`/`%d`/`{0}` placeholders kept in count and order. Wording follows the Taiwan official client. |
| **Tests**                | New tests must not depend on Chinese text: CI runs the tests with the ui_zh commit reverted. A test that fails only because of translated text is not a bug in the code.                                                                                                           |
| **Claims in the PR**     | A PR description must not state that something was tested when it was not. Ask for the evidence (test, log line, request result) behind any claim about runtime behavior.                                                                                                          |

## Checked by CI

`caddo CI` runs `.github/caddo-checks/conventions.mjs` on every change: C1 interface paths in `data-*`, C2 resource names and the loader defaults, C3 private-network addresses and the deployment values kept in a repository secret, in every commit (a value removed again is still public), C4 one ui_zh and one patch commit, C5 a test with every fix meant for upstream. A red check names the rule and the line. Review what those patterns cannot see: a resource name decoded through a variable or a helper, a path built in another file, a deployment value in another form, a test that does not test the change.

## Known, not to flag

- The ui_zh commit changes about a thousand UI strings; review it for broken code (see above), not for each wording choice.
- `caddo CI` excludes `tests/ui/Navigation.airship.test.js` (the patch shows map names through `DB.getMapName`, which that test's DB mock lacks) and `tests/ui/WriteRodex.characterInfo.test.js` (job names come from the Chinese `JobNameTable`).
- `animation.tick` is the start time of the current action, not a redraw signal; the renderer reads `files.*.spr/act` every frame.
